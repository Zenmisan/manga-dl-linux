## ⚠️ Known Issues (Blocking Phase 1 Completion)

### CRITICAL (Must Fix Before R3 Audit)

1. **Blocker #2: Synchronous apiFetch**
   - Impact: HIGH — All network calls block worker thread; searches are serialized
   - Current: `HttpService::fetch()` uses nested QEventLoop
   - Required: Truly async network with signal-based completion
   - Affected: `HttpService.{h,cpp}`, `JsWorker.cpp`

2. **Blocker #3: DOM Snapshots**
   - Impact: CRITICAL — 17 novel sources fail
   - Current: `innerHTML`/`textContent` are snapshots at element creation
   - Problem: `element.remove()` doesn't update parent's innerHTML
   - Required: Lazy JS getters reading live dom::Document
   - Affected: `Dom.{h,cpp}`, element wrapper construction in `JsWorker.cpp`

3. **Blocker #4: Use-After-Free**
   - Impact: CRITICAL — Memory corruption risk
   - Problem: Elements hold raw `dom::Document*` without ownership
   - Required: Elements keep strong JS reference to document OR use shared_ptr
   - Affected: `Dom.{h,cpp}`, finalizer logic

4. **Finding #5: decodeURIComponent Breaks Non-Latin-1**
   - Impact: MEDIUM
   - Fix: Remove override, use QuickJS built-in (already correct)
   - Affected: `JsWorker.cpp` (1 function removal)

### IMPORTANT (Required for Production)

5. **Finding #6: Descramble Bugs**
   - Comixto: Seeds >2^31 parsed wrong (use `toUInt()`)
   - URLs percent-decoded twice
   - WebP needs Qt imageformats plugin
   - Asura: tiles format mismatch

6. **Finding #7: Deadline Handling**
   - Shared deadline; nested calls break timeout

7. **Finding #8: No Real Extension Tests**
   - All tests use toy scripts
   - R3 audit: Test all 40 real scripts with fixtures

8. **Finding #9: HttpService Gaps**
   - No binary fetch with Referer (needed for images)
   - No charset detection (some sources use Shift-JIS/GB2312)
   - Transport failures (status 0) not surfaced as errors

### MINOR (Polish)

9. **Finding #10: Warnings**
   - Format string: `%d` vs `qsizetype`
   - Deprecated `QVariant::type()` calls

- **JS Engine**: QuickJS-ng v0.17.0 (only option with async/await support)

- **Threading**: One dedicated worker thread for all JS execution
- **Extensions**: 40 scripts from QRC, 23 novel / 21 manga sources
- **Descramble**: Native C++ implementation (comixto, asura)
- **Trackers**: AniList + MAL only (4 others removed per R4 decision)
